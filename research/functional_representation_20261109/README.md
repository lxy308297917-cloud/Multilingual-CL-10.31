## 以下为执行前冻结的研究计划（非当前完成状态）

# 功能敏感表示约束：下一阶段实验

## 目标与当前范围

验证在多语言适配中，旧能力相关的表示变化能否提供超出总漂移或整体更新减小的解释力，再决定是否进入表示约束训练。先完成SW；规则冻结后才扩展AR/RU。当前先准备数据和代码；已有实验A的18组测评、报告、复核和GitHub交付继续完成。

本计划根据2026-11-09最新讨论更新。实验A完整交付继续进行；新阶段先准备独立校准材料，再按机制证据决定是否进入训练。本文记录计划，不宣称新方法已经训练或有效。

## 研究依据与边界

- [LinguaMap](https://arxiv.org/html/2601.20009v2)提供层级语言表示分析和选择性SFT的启发；我们的候选方向增加训练中的表示约束，需要单独验证。
- [Two-Phase CFT](https://aclanthology.org/2026.findings-acl.1595/)研究多语言适配时的表示变化，以及回放、层冻结干预。本文不能替我们证明新约束有效。
- 既有消融观察是候选机制的来源；正式测试结果已暴露，不能作为新算法的开发反馈或层数选择依据。
- 功能敏感梯度CE是可微代理，不能称为IFEval损失。低维保护可能限制有益变化，不提供不遗忘保证。

## 阶段P0：独立校准候选池（CPU准备）

共512候选：数学/指令各256，每类事先分build128、check128。数学来自锁定GSM8K train，排除正式test问题以及当前4B Base/LoRA正式5-shot提示中出现过的训练题。指令为8类原创、可程序核验的约束及有效参考回答；build/check值不同，但共享模板，须报告此局限，不冒充官方IFEval。

采用与4B相同的non-thinking模板，核验固定回答前缀和assistant监督边界。接下来由适配前模型生成回答，按冻结顺序每个split/能力选前64个Base正确样本。候选不足时如实报告，不从正式测试补入。Base错误的回答不会被当作必须维持的正确能力。

build用于构造方向，并在以后需要时作为额外校准训练资源；check只做机制检验，不进入方向构建、训练反传或阈值调节。记录来源、顺序、文件哈希、实际输入/监督token和Base筛选曝光。

## 阶段P1：不新增训练的机制判别

先SW，复用Base、Full LoRA、Remove-Middle，以及总有效ΔW范数匹配的统一缩放LoRA。统一缩放系数仅由权重范数计算：`a=||ΔW_remove_middle||F/||ΔW_full||F`，不根据任务分数选取。

在固定输入和固定参考回答前缀上，区分问题末位置、回答起始位置及回答内部位置。用build样本旧回答CE对各Transformer block输出的梯度，按数学/指令分别提取低维正交基。第一版固定rank8，覆盖36层；不按正式成绩选层。使用同rank随机正交方向作为机制对照。

在check样本上同时记录：总表示漂移、投影到敏感方向的漂移、随机方向漂移、参照特征尺度、旧任务CE及可核验的实际回答正确性。报告方向构造与检验样本不重叠；题目、模型变体与层间存在依赖，不能将全部单元当作独立重复。

本阶段回答信号是否值得投入训练，不声称提高目标benchmark。若相对于总漂移、匹配统一缩放或随机方向没有额外证据，记录负结果并暂不启动复杂约束训练；保留真实任务分数，不按代理指标宣称新方法有效或无效。

## 阶段P2：条件成立后的SW固定预算训练

四组均使用同一6400条SW目标数据、样本顺序、seed42、完整400步、有效batch16、rank16/alpha32和现有学习率/优化器配方。固定Final400为主要比较模型，保存0、50、100、200、300、400节点，不用英语退化早停，也不选最高测试分checkpoint。

|组别|额外训练信号|
|---|---|
|All-layer LoRA轨迹基线|无旧能力约束，重新保存中间节点|
|普通表示保持|同池、同层、同位置的全表示保持|
|功能敏感表示保持|同池、同层、同位置的rank8投影保持|
|英语CE回放|使用完全相同的旧能力build材料|

第一版使用固定强度。归一化、强度和旧池采样频率在工程预检后、正式比较前冻结；不同时叠加动态门控、稀疏选择和梯度投影。全表示与功能敏感组须匹配额外校准批次；CE回放获得相同旧信息。分别记录额外token、前后向次数、特征缓存、时间和存储，不能宣称无回放或等总计算量。

主要正式任务沿用目标/EN Belebele、原生XL-Sum、GSM8K flexible、IFEval prompt strict；GSM strict/IFE instruction strict及SW Global-MMLU继续保留。中间节点优先使用预先冻结的同任务形式开发材料；正式端点不用于调系数。旧翻译、XNLI历史结果保留，本轮不以其未稳定收益挑选方法。
