# 解释边界（正式结果完成前冻结）

1. **当前是三种独立单语适配。** 每种语言都从同一官方 Qwen3-4B 开始，不是 SW→AR→RU 顺序训练；本轮不能证明顺序持续学习有效。
2. **首轮仅 seed42。** 题目级配对区间反映固定这次训练得到的模型在当前题目上的变化，不代表跨训练种子的稳定性。Bootstrap 随机数不是新增训练种子。
3. **测试集存在历史曝光。** 既有 Base、普通 LoRA 和 SW36点 FullRep 的正式测试结果已用于发现现象和确定本轮研究方向。因此这些测试不是全新盲测。当前六组权重只依赖冻结的 build 校准材料；本轮不据正式分数改权重、改方法、选择 checkpoint 或选择运行。
4. **语言间任务和数据量不能当作语言因素的单独因果效应。** 各语言同为6400例、400步，但 token 数、阅读材料和翻译来源不同；摘要正式测试 SW987、AR4689、RU7780，ROUGE 分词也沿用各语言既有协议。按每种语言内部比较，不比较跨语言 ROUGE 的绝对水平，不把三种语言当作三个训练种子。
5. **校准是算法输入，不是成效。** 减弱组更新后的 CE 损伤/收益只用于一次性构造保护权重，不能单独证明 benchmark 提升、功能分离或因果干扰。SW复用已保存的 build CE；此前用于多选诊断的阅读干扰选项不参与这里的 CE。AR/RU 同样采用参考短答案 CE 和摘要 CE，没有再次以短训成绩决定是否进入正式400步。
6. **Attention/MLP表示点是残差流位置，不是独立功能。** 每层 post-attention residual 和 post-MLP residual 都包含前序更新的影响；六组加权不等于独立定位六种功能。它们组成新的共同72点特征定义。旧36点 SW FullRep 单列保留，不能混称为新72点均匀基线。
7. **强历史对照不能消失。** 即使候选超过新72点均匀基线，也必须同时展示已有 SW36点强基线。若仍低于旧强基线，要如实说明；不得仅凭换了表示点后的主表宣称超过原先最强表示保持。
8. **校准 adapter 与主训练身份分开。** SW权重来自已完成的 batch2 普通LoRA；AR/RU 权重来自既有 batch1 普通LoRA。新主表中AR/RU普通LoRA及所有新增方法统一 batch2、GA8。所有方法的目标样本/标签流逐条对齐各语言原始6400例。不会在新 batch2 模型完成后再用正式结果重新拟合权重。
9. **保护预算的定义有限。** 六权重均值1、上下界0.5和2、相同 EN build128 和共同 Base 特征，只保证标量损失系数预算及信息来源对齐，不保证实际梯度范数、参数更新范数或目标能力学习速度相等。报告有效 ΔW 范数、漂移和目标学习变化；如有效，也不能仅据本轮断言优于所有更新幅度匹配的替代解释。
10. **标定尺度预先固定。** 72点表示尺度与 KD 尺度都通过同一历史 SW adapter、相同 EN build128、相同 Base 确定，再在三语言间共享；没有逐语言调 λ。该选择可能并非各语言最优，但本轮不根据测试分数重新调节。
11. **额外数据和计算分开计入。** 普通LoRA没有额外旧任务 backward；均匀、随机、功能表示保护以及 KD 每目标 microbatch 都读一个相同顺序的旧样本。KD采用稠密输出分布，表示方法采用隐藏特征，教师信息张量和储存规模不等价。共同缓存、固定权重校准、2步工程验证、旧方案被取消后已耗计算量均单列，不合并成正式400步预算。
12. **XNLI选项偏好与生成评分限制保留。** ACC按固定候选似然计算；此前已发现明显选项偏好，不能把全部ACC变化都解释为语言推理增长。GSM8K主指标为灵活数值提取，另保留 strict；IFEval保留官方提示级和指令级 strict。HumanEval+只接受已有隔离执行器的真实执行结果，静态代码检查不替代通过率。
13. **区间和多重比较。** 预先报告同题配对区间，XNLI按共享premise分簇，阅读按共享文章分簇，摘要按文章、数学/代码按题目。它们不是经过多重比较校正的显著性声明，不以区间跨零与否选择新超参数。
14. **未解决的翻译问题不被本轮覆盖。** 本轮按最新计划测四项目标和六项通用能力；既有翻译退化和数据源对照保留为历史问题，不声称表示保持已经修复翻译。

- 随机加权是一个预先固定排列，不能据此估计所有随机排列的分布。权重输入的独立审计以校准DONE、原始校准哈希和文件先于训练的时间为证据；这是对冻结输入的事后复核，不冒称另有未实际保存的训练内权重日志。
