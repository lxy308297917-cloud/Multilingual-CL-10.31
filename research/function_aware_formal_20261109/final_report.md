# 多语言适配正式结果：功能风险表示保持与5+5补测

2026-11-10T09:22:21.025648+08:00

## 结论与完成边界

本阶段已完成22个可运行模型/语言端点的220项5+5分数，及AR/RU的10个XQuAD端点。原计划的5个未启动训练、额外翻译和GPU机制诊断仍由用户暂缓；本报告不宣称原研究整体已经全部完成。

普通LoRA在目标语言阅读/摘要等获得收益，同时出现数学、指令或代码能力下降。均匀与随机表示保持已经是很强的对照。当前静态功能风险加权尚未显示超越这些强对照的明确总体优势；保留有利变化、无明确差异和退化结果，不把负结果改写成算法成功。

## 设置与公平比较

- 模型为官方posttrained Qwen3-4B，revision `1cfa9a7208912126459214e8b04321603b3df60c`，不是Qwen3-4B-Base。三语言分别从同一模型独立适配，不是顺序CL。
- 每种语言6400条，固定Final400、seed42、有效batch16、micro2/GA8、长度2048、BF16、assistant-only、non-thinking、不packing。LoRA r16/alpha32/dropout0.05、LR1e-4；不因英语退化早停，不按正式测试选checkpoint。数据流/监督token和初始权重身份见training_artifact_audit.json。
- 新表示保持在36层的post-attention/post-MLP残差位置共72点上定义，前/中/后12层×Attention/MLP形成六组。普通LoRA无额外旧任务计算；均匀、随机、功能和KL共享旧build128及实际3200次旧样本曝光。共享数据不等于同一教师张量或相同计算成本。
- 功能权重仅由冻结build校准CE、固定0.75单组减弱及精确总有效更新范数匹配的统一缩放对照构造；权重和6、范围[0.5,2]、总系数1。校准是算法输入，不是效果证据。随机为预定排列且权重多重集相同，无新训练种子。
- SW校准器是既有micro2模型；AR/RU校准器是历史micro1模型。新的正式比较均micro2，历史micro1另见三语言基线报告。SW旧36点FullRep保留为强参考，但不冒充同72点特征的严格权重消融。

## 评测协议

目标5项：Belebele ACC（900题）、XNLI ACC（5010题）、XL-Sum ROUGE-Lsum（SW987/AR4689/RU7780）、Global-MMLU ACC（每语言14042题/57学科/5-shot）、SIB-200 acc_norm（每语言204题/0-shot）。通用5项：GSM8K flexible-extract（1319题）、官方IFEval prompt strict（541提示）、HumanEval+真实隔离执行pass@1（164题）、EN MMLU ACC（14042题/57学科/5-shot）、EN Belebele ACC（900题）。其他提示、解码和评分沿用冻结协议，未据本轮测试调整。EN XNLI、GSM strict和IFEval instruction strict另列，不混入主指标。

## 结果解释

1. SW候选相对普通LoRA有阅读与部分通用保持收益，但对均匀、随机及旧36点强参考并无明确总体优势。必须保留同池KL、随机和旧强参考；不能只与普通LoRA比较来证明功能分配有效。
2. AR候选保持数学、指令和代码更好，但比对齐普通LoRA的阅读低1.78pp、XNLI低4.19pp。摘要20.82与普通20.83接近；缺失的AR均匀/随机/KL训练限制了功能分配的归因。
3. RU候选相对均匀：阅读同分、摘要+0.045、数学-0.61、IFEval+1.29、代码同分，相关配对区间跨零；EN阅读和补充EN XNLI更低，区间不跨零。相对随机，RU知识和XNLI有正差异，但通用保持未形成全面优势。
4. 各组有效更新范数及额外旧任务计算见training_artifact_audit.json与compute_costs.json。权重系数预算相同不保证梯度/更新范数相同；六组残差位置不等于独立功能，不凭CE或表示代理宣布因果机制。

## 新增benchmark的限制

- SIB主指标为Harness按标签字符长度归一化的似然ACC；原始ACC、Macro-F1、混淆矩阵均保留。部分模型偏向第一且最长标签，主指标的大幅差异不能全解释为语义能力变化。AR原始ACC也下降，因此不能全归因于归一化。SIB与Belebele有大量文本包含重叠，不是独立文本证据；不据分数删任务或切换主指标。
- XQuAD仅支持AR/RU，各1190题/240段文章，官方EM/F1直接评分原始输出。Base低EM受额外答案词语和格式影响，不能把全部提升解释为理解能力。AR候选F1与普通差异不明确；RU候选低于普通但高于均匀/随机，完整负结果保留。
- HumanEval+为真实执行，静态代码检查不替代通过率。IFEval主表已更正为prompt strict，历史三行误映射更正记录保留；原始预测未改。
- 全部只seed42；配对区间针对固定模型的样本不确定性，不代表训练种子稳定性，未作多重比较校正。区间跨零不证明等效。部分正式测试已有历史曝光；本轮权重未依据新正式分数拟合。

## FFT补充与未解决问题

SW FFT+原36点保护的排定补测已完成，阅读/摘要等有收益，仍有指令和代码退化。匹配普通FFT被用户暂缓，历史FFT与新训练实现存在差别，不能将差异完全归因于保护损失。本轮没有修复翻译，也没有提供顺序CL有效性证据。
