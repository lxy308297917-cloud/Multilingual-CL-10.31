# NLLB替换20%翻译样本：固定训练对照

## 实际改动

保留原5120条非翻译样本及其位置，只替换1280条双向翻译样本。640独立句对×双向，6400条训练一遍、400步，effectivebatch16，LoRA r16/alpha32/dropout.05、七投影、LR1e-4、AdamW/cosine/warmup.05、seed42，官方Qwen3-4B revision1cfa9a7208912126459214e8b04321603b3df60c。assistant-only/nonthinking/BF16/长度2048/不packing，固定Final400，无英语下降早停。

## 旧NLLB来源复用

归档train.jsonl、indices.json、manifest.json的SHA256与旧发布身份一致。从旧D2实际44292次呈现中，筛出两方向均被采用的5694组NLLB数据，再固定哈希抽640组。没有把整个47499组候选池冒充旧D2实际训练子集。使用保存的原始文本，按当前4B模板重新编码，没有沿用Qwen2.5 token IDs。旧原始数据的上游过滤没有重新运行，不宣称母语人工认证或完整复现旧D2。

## 解释范围

本轮只能检验在当前4B、当前6400条/400步配方下的NLLB替换结果。不能因为旧D2总体有效就断言640组NLLB在本配方必然有效，也不能把本轮没有可靠收益推广为NLLB不可学习。重复率是固定4gram启发式，正常终止不能证明语义忠实。

原三条训练及结果保持独立，无覆盖；其他语言泛化继续暂停。

## 当前翻译结论

1. NLLB替换没有修复EN→SW贪心重复：重复率69.57%，chrF++8.83，仍低于Base14.90。不能称为翻译问题已解决。
2. NLLB的SW→EN比原混合LoRA更好，但与Base相比，两种解码的配对区间都跨零，尚无可靠的超越基座证据。
3. EN→SW采样下，NLLB15.16与原混合15.15接近，低于清洗GlobalVoices混合17.55。当前数据不支持采用NLLB替换作为统一修复方案。
4. 清洗GlobalVoices混合的EN→SW采样相对Base为+1.80 chrF++，配对95%区间[+1.00,+2.65]；同时SW→EN仍低于Base。这是单训练/推理seed下的协议相关收益，不能概括为双向翻译全面提升，也不能覆盖原贪心负结果。
5. 数据选择与解码都影响结果，但本轮没有证明某个具体噪声样本或多任务梯度冲突导致退化。下一轮训练方案需用户确认研究方向后再定，本目标不扩展训练搜索。
